# UI primitives

Buttons, inputs, dialogs, tables, alerts and related presentation building blocks.

## When working here

Use consistent styling/accessibility. Avoid embedding commerce policy or database access in presentation primitives.

## Where to start

- [button.tsx](button.tsx): Common button styling and behavior.
- [dialog.tsx](dialog.tsx): Base UI dialog wrapper; verify labels, focus and keyboard behavior in each consuming screen.
- [input.tsx](input.tsx): Shared input primitive.

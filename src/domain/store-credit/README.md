# Credit refund allocation

Pure allocation of purchase refunds across credit funding.

## When working here

Cap refunds by original source funding and prior compensation; never turn credit into a synthetic external receipt.

## Where to start

- [refund-allocation.ts](refund-allocation.ts): Allocates refunds against original credit funding.

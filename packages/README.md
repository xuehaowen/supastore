# Shared contracts and helpers

Serializable contracts, localization and destination helpers shared across applications.

## When working here

Share data/rules that can safely cross the service boundary, not backend credentials or persistence dependencies.

## Where to start

- [HTTP contracts](contracts/README.md): serializable backend/storefront response types.

- [Shared customer localization](i18n/README.md): Locale selection, customer messages/error localization and document-language helpers.
- [Shared shipping helpers](shipping/README.md): Destination matching helpers reused by backend and storefront.

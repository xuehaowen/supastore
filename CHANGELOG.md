# Changelog

## Unreleased — developer beta

This source is being prepared for an initial developer-beta release. No entry
below establishes a supported production release or real merchant acceptance.

- Independently deployable Next.js storefront and merchant backend.
- Product/variant catalog, collections, stock, customer accounts, payments,
  refunds, returns, store credit and rewards.
- English/Chinese customer flows, policy pages and contextual commerce rules.
- Batch product-image uploads with per-file descriptions and failed-only retry.
- Explicit console SMS previews, with silent disabled mode and separate live authorization.
- Transactional outbox delivery, scoped authentication, private storage and recovery tooling.
- Isolated Docker demo, private vulnerability reporting and contributor templates.
- Release workflow for versioned backend/storefront/migration images, gated on CI.

Production provider/HTTPS/recovery acceptance and the observed human merchant
pilot remain pending. See [beta release checklist](docs/beta-release.md).

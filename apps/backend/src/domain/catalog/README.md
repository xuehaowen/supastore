# Catalog calculations

Variant combinations, CSV interpretation and historical item names.

## When working here

Generation must preserve stable existing variants. Display accepted item snapshots instead of substituting current product labels.

## Where to start

- [order-item-name.ts](order-item-name.ts): Displays names from accepted order-item snapshots.
- [product-csv.ts](product-csv.ts): Parses and validates product CSV data.

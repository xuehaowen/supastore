# Storefront pages and proxy route

Localized shopping/account/order pages, client interactions, recovery, SEO and API proxy entry point.

## When working here

Use lib clients/proxy helpers. This page tree does not mirror every category/collection/content/search route in the combined app.

## Where to start

- [commerce.tsx](commerce.tsx): Customer shopping and checkout interactions.
- [account-client.tsx](account-client.tsx): Account history, profile and credit interactions.
- [order-client.tsx](order-client.tsx): Order payment, evidence and return interactions.
